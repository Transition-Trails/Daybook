Enhance the WorldSmith Prompt Compiler by replacing the current "Full Compiled Prompt" experience with a true "Compiled Production Specification Inspector."

The compiler is no longer simply assembling text. It is compiling a governed production artifact from multiple approved specifications. The UI should reflect that architecture and make the compilation process transparent, explainable, and easy to debug.

This feature is intended to become the primary inspection tool before Product Specification Preview generation and final image generation.

==================================================
OBJECTIVE
==================================================

Transform the compiler results page into a structured inspection experience that allows users to understand:

• what was compiled
• where every instruction originated
• what inherited correctly
• what validation warnings exist
• what still needs attention before generation

The goal is to eliminate the need to scroll through a 14,000+ character prompt to understand the compilation.

==================================================
REPLACE
==================================================

Replace the current:

Full Compiled Prompt

Compiled Production Specification

==================================================
ACCEPTANCE CRITERIA
==================================================

The feature is complete when:

• Users no longer need to inspect one massive prompt block to understand compilation.

• Every compiled section has visible provenance.

• Every inherited specification is visible.

• UUIDs are replaced by friendly names.

• Validation references governing specifications instead of hardcoded assumptions.

• The compilation process resembles a professional publishing build pipeline.

• The page clearly communicates what was compiled, where it came from, what still needs attention, and what the next production step is.

The compiler should feel like the authoritative inspection and governance tool for the WorldSmith publishing pipeline, not merely a prompt viewer.
