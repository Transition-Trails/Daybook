---
name: Wychcombe environment divergence
description: Why World Creative Director content needs a source-checked production application update after schema publication.
---

Development and production have distinct Wychcombe World and Origin Story records. The development Origin Story has no summary, while the production Origin Story carries the authored narrative source. Publishing the new schema does not transfer development editorial data into production.

**Why:** Replacing production data with the development fixture would lose the authoritative source material and unrelated production edits.

**How to apply:** Publish additive schema changes normally. Then migrate the intended production World through its authenticated, revision-checked application edit path using the existing production Origin Story as source, verify the saved fields, and leave the Origin Story, world rules, lifecycle state, and Canon untouched. Do not use Publish's data-overwrite option for this.
