---
name: Canon image export approval
description: Why a primary gallery image does not automatically qualify for snapshot export
---

The editor's primary designation expresses editorial intent, while asset approval and canonical strength determine export eligibility. An image can be designated primary but still be a draft; an approved reference does not become the primary just because it is the only exportable asset.

**Why:** A real Canon record had a designated but unapproved primary and a separate approved reference. Silent promotion would publish the wrong authoritative image, while treating the mismatch as an unhandled error hid snapshot status from editors.

**How to apply:** In image exports, validate primary designation against eligible assets before downloading or publishing. A gallery or portrait with no asset rows is not evidence of approval: editor saves can publish before asset metadata is persisted. Return a reviewable blocker and let an editor save and approve the intended primary or designate an approved alternative. Do not repair production Canon data automatically.
