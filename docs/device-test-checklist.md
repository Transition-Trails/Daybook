# Daybook Device Test Checklist

> **Purpose:** Verify that a generated planner works correctly when opened on a real device — that navigation links resolve, annotation persists, stickers behave, and e-ink variants are readable.  
> **When to run:** Before any public release. One session covers all four test files.  
> **Files:** Generated by `pnpm --filter @workspace/api-server run generate:test`. The script prints Drive links and stats. Open each file on device from Google Drive.  
> **Recording results:** Fill in the "Actual" column for each item. A test **fails** if Actual ≠ Expected. Any failure is a blocker unless marked *(advisory)*.

## 10 · Kindle Scribe Advisory *(advisory — not a blocker)*
