Daybook Feature Definition: Production Profiles & Disc-Bound Output Infrastructure
Objective

Add a reusable Production Profile system to Daybook that defines the physical or digital output geometry for planner and journal assets.

The purpose is to separate:

creative design
component behavior
production dimensions
binding requirements
punch geometry
final export behavior

A single source design should eventually be capable of producing multiple outputs such as:

digital planner pages
9-disc Happy Planner Classic pages
Half Letter disc-bound pages
Letter-size disc-bound pages

This implementation is infrastructure only.

Do not implement PDF resizing, hyperlink generation, page imposition, punch-hole drawing, page assembly, or final planner export in this phase.

4. Calculated Safe Areas

Add calculation logic that determines the usable content rectangle for a page.

The system should distinguish three concepts:

Bleed Area

Artwork may extend beyond trim into bleed.

General Safe Area

Critical content should stay at least the configured Outer Safe Margin from non-binding trim edges.

Binding Safe Area

Critical content must remain outside the configured Binding Safe Zone.

For a mirrored profile:

Recto / Right-Hand Page

Binding edge is left.

Conceptually:

| 0.75" binding-safe zone | usable content area              |
Verso / Left-Hand Page

Binding edge is right.

|              usable content area | 0.75" binding-safe zone |
5. Critical vs Background Content

This distinction is mandatory.

Do not interpret the Binding Safe Zone as blank space.

Background artwork may extend through:

binding zone
trim
bleed

Examples:

paper texture
foxing
subtle botanicals
background color
faint ledger ruling
nonessential decorative material

Critical content must remain outside the binding-safe zone.

Examples:

body text
page titles
writing fields
hyperlinks
tabs
buttons
page numbers when binding-adjacent
labels
focal objects
essential illustration
important borders
functional controls

The future rendering/export engine will use this distinction.

This phase only needs to establish the rule and geometry.

6. Page Side Support

Add or reserve a page-side property:

Page Side

Options:

Unspecified
Recto / Right
Verso / Left

When a Production Profile uses Mirrored binding:

Recto resolves binding edge to Left
Verso resolves binding edge to Right

If Page Side is Unspecified, Daybook should not guess.

Instead, display the profile's binding zone as unresolved until page sequencing supplies the side.

7. Relationships

A Production Profile should eventually be attachable to:

planner projects

For this phase, add the relationship in the most appropriate existing production/output model without forcing Production Specs to duplicate profile information unnecessarily.

9. Visual Safe-Zone Preview

Add a simple preview diagram to the Production Profile editor.

It does not need to render artwork.

Show:

Include controls to preview:

Recto
Verso

For mirrored binding, changing Recto/Verso should visibly flip the binding-safe area.

Use labels such as:

Trim
Safe Content
Binding Safe Zone

This preview is a geometry visualization only.

10. Validation Rules

Add validation for:

width > 0
height > 0
margins cannot exceed usable page dimensions
bleed cannot be negative
binding-safe zone cannot be negative
disc-bound profiles require a binding-safe zone
digital profiles cannot require a punch template
Mirrored requires Page Side during downstream page resolution
profile codes must be unique

Do not require Punch Template geometry to be complete for a Production Profile to exist.

A Punch Template may remain in Testing.

Those are future phases.

12. Acceptance Criteria

The feature is complete when:

I can create/edit/archive Production Profiles.
The four seed profiles exist.
Disc-bound profiles store a 0.75" binding-safe zone.
Happy Planner Classic is defined as 7 × 9.25", 9-disc.
Half Letter is defined as 5.5 × 8.5".
US Letter is defined as 8.5 × 11".
Punch Templates exist as separate records.
Production Profiles can reference Punch Templates.
Recto/Verso preview correctly mirrors the binding-safe zone.
Background-safe vs critical-content behavior is documented in the model/UI.
No PDF/export functionality is added yet.
Existing Production Specs, Component Specs, Style Guides, Prompt Modules, and WorldSmith records continue to function without regression.
Final instruction to Replit

Implement this as extensible production infrastructure rather than planner-specific hardcoding. Production Profiles define output geometry and safe areas. Punch Templates define physical punch geometry. Keep creative specifications separate from manufacturing/output constraints. Do not add export or PDF-generation behavior in this phase.
