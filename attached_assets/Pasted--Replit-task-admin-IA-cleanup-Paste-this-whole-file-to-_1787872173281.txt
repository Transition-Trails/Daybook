## 1. `sixPointSeries` fabricates a cliff to zero

`pages/super/Dashboard.tsx`

```ts
function sixPointSeries(values: Array<number | null> | null | undefined) {
  return Array.from({ length: 6 }, (_, index) => values?.[index] ?? 0);
}
```

Every metric is padded to exactly six points, filling gaps with `0`. So a platform with three
months of history renders three real points followed by a hard drop to zero — the sparkline
reads as a collapse. A `null` mid-series does the same thing in the middle of the line. This is
the one thing on the dashboard that can actively mislead.

Fix: drop the padding. Pass through only the points that exist, filtering `null`.

```ts
function series(values: Array<number | null> | null | undefined) {
  return (values ?? []).filter((value): value is number => value !== null);
}
```

`MetricStrip` already falls back to "Trend unavailable" when it gets fewer than two points, so a
short or empty series degrades correctly on its own. Do not add a floor, a zero-fill, or a
minimum length.

Also confirm `billingTrends.revenue` and `billingTrends.conversion` are ordered oldest → newest.
`Sparkline` plots index 0 at the left, so a newest-first array draws every trend backwards. If
`billingTrendValues` returns newest-first, reverse it there, not at the call site.

**Acceptance:** with only three months of data, the sparkline draws three points and no descent
to zero. A metric with one data point shows "Trend unavailable" rather than a flat line.
